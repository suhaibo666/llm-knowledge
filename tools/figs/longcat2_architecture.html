Base 词嵌入

→ e₀ : 8,192
16 路 n-gram 哈希嵌入　(n=2,3,4,5) × (k=4 split)
① 多项式滚动哈希：id = Σ tokenδ·vocabᵟ mod mn,k（compute_n_gram_ids）
② oe_embeder 查表 → 每路 512 维（= 8192 / 16）
③ oe_projection 逐路投影回 8,192 → e₁ … e₁₆
平均：mean(e₀, e₁ … e₁₆) 共 17 项 → 最终 embedding 8,192
哈希查表几乎不增 FLOPs；把「多 token 组合」信息直接注入输入嵌入。参数 135B 主要活在 oe_embeder 哈希表（每 (n,k) 表 ≈ m 项、m≈vocab×100）
「MoE 稀疏度已过甜点区」→ 与其继续堆专家，不如在与 MoE 正交的稀疏维（哈希嵌入）廉价扩参；收益「远超同等规模纯 MoE」（README / blog）。承袭自 LongCat-Flash-Lite。

轻量 Indexer 打分
index 32 heads × dim 128 · 为每个 query 给全体 KV 打分
SI：强制保留 + 动态选（合计 top-2,048）
恒保留 16 sink + 1,024 local（连续 ≈ 半预算）；其余 ≈ 1,008 动态选（block 对齐、coalesced）
在选中的 2,048 个 KV 上算稀疏注意力 → o_proj → ⊕ 残差
CLI：索引一次算好后，本层 attn0/attn1 共用，且每 2 层（cli_factor=2）复用一次、3 个 MTP 草稿步共用一次 —— 复用的是索引集合（缓存），不是注意力结果，每层仍用自己的 KV 算 Attn。HI（块级粗筛→细选的两级索引）是训练-free、用于超长任务；SGLang 推理「for simplicity」暂未实现。KV cache 推理为 bf16、权重为 FP8（LongCat-2.0-FP8）。
