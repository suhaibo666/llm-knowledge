三轮请求共享同一前缀：朴素路由每轮落到不同 rank → cache miss → 重算 O(总上下文)；DP-aware 用一致性哈希把 rollout 钉死到同一 rank、复用其本地 KV，prefill 只付增量 token O(Δ) 的钱，且不需跨 rank 同步 KV。叠加哈希空间上的轻量负载再平衡防倾斜；与 §3.6.2 的 DP-attention「不跨 rank 复制 KV」是同一思想的路由层版本（§4.1.2, p17）。
