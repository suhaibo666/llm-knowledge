两处池化刻意不同：键压缩用 AvgPool（键是稠密内容，取均值才是合理汇总）； 蒸馏时把教师注意力分布对齐到块级却用 MaxPool——教师分布稀疏且尖峰，一个块里往往只有一两个 token 真正重要， 取均值会把这个信号摊平。
实测收益（Figure 6，1M 上下文）：indexer 本身 prefill 3.8× / decode 4.4×； 含 indexer 与稀疏 core attention 在内的整个注意力模块相对稠密 GQA 为 prefill 7.6× / decode 4.9×。 质量上 QSA 不但没掉，长上下文反而更好（RULER 512K–1M：90.08 → 93.00）。
