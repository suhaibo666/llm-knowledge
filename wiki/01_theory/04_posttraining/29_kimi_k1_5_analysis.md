## 一、核心问题：RL 作为新的扩展维度

传统预训练受限于高质量数据总量。Kimi k1.5 探索 **RL 作为新的扩展维度**：

```
传统预训练扩展:  模型参数↑ + 数据量↑ → 智能↑ (受限于数据总量)
RL 扩展:        模型通过奖励信号自主探索 → 生成训练数据 → 持续改进
```

**核心假设**：更长的上下文长度 ≈ 更多的搜索步数 ≈ 更强的推理能力

## 二、训练流程：四阶段

```
预训练 → 常规 SFT → Long-CoT SFT Warmup → RL 训练
```

| 阶段 | 关键内容 |
|------|---------|
| **预训练** | 多模态数据，三阶段：VL预训练 → Cooldown → 长上下文激活 (4K→32K→128K) |
| **常规 SFT** | 100万文本 + 100万视觉示例 |
| **Long-CoT SFT** | 提示工程构建高质量长思维链数据集（规划、评估、反思、探索） |
| **RL 训练** | GRPO 变体，128K 上下文 |

## 三、RL 算法：在线镜像下降变体

### 3.1 优化目标

$$\max_\theta \mathbb{E}_{(x,y^*) \sim \mathcal{D}} \left[ \mathbb{E}_{(y,z) \sim \pi_\theta} [r(x, y, y^*)] - \tau \mathrm{KL}(\pi_\theta(x) || \pi_{\theta_i}(x)) \right]$$

### 3.2 梯度更新

$$\frac{1}{k} \sum_{j=1}^k \left( \nabla_\theta \log \pi_\theta(y_j, z_j|x) (r(x, y_j, y^*) - \bar{r}) - \frac{\tau}{2} \nabla_\theta \left( \log \frac{\pi_\theta(y_j, z_j|x)}{\pi_{\theta_i}(y_j, z_j|x)} \right)^2 \right)$$

### 3.3 与 GRPO 对比

| 特性 | Kimi k1.5 | GRPO (DeepSeek) |
|------|-----------|-----------------|
| 基线 | 组内奖励均值 $\bar{r}$ | 组内奖励均值 |
| KL 正则 | $L_2$ 正则化形式 | KL 散度惩罚 |
| 理论来源 | 在线镜像下降 | PPO 简化 |
| 价值网络 | ❌ | ❌ |

### 3.4 为什么不用价值网络？

> 探索错误路径对训练模型生成长 CoT 极其有价值——模型可以从错误中恢复并找到正确答案，从而学习试错模式。

### 3.5 长度惩罚

$$\lambda = 0.5 - \frac{\mathrm{len}(i) - \mathrm{min\_len}}{\mathrm{max\_len} - \mathrm{min\_len}}$$

- 正确答案中：奖励较短回答，惩罚较长回答
- 错误答案中：明确惩罚长回答
- **渐进式引入**：初期不使用，后期加入

## 四、RL 扩展定律

### 4.1 上下文长度扩展

```
性能 ↑
  │     ╱ (困难基准)
  │   ╱
  │ ╱   ╱ (中等基准)
  │╱ ╱
  │╱ ╱ ╱ (简单基准)
  └──────────────→ 上下文长度
       32k    64k    128k
```

**关键发现**：
- 响应长度和准确率**同步增长**
- 更困难基准表现出**更陡峭的响应长度增长**
- 扩展到 **128K 上下文**，困难推理持续改进

### 4.2 模型大小 vs 上下文长度

- 小模型 + 长上下文 ≈ 大模型性能（预算受限时可行）
- 大模型 + 长上下文 = **最高性能上限**
- 大模型有更好的 token 效率

### 4.3 负梯度的重要性

使用负梯度惩罚错误回答，样本效率显著优于 ReST（不使用负梯度）。

## 五、关键创新

### 5.1 简化框架

```
传统方法: MCTS + Value Function + Process Reward Model
Kimi k1.5: 长上下文 + 改进策略优化 = 隐式搜索
```

### 5.2 Partial Rollouts

```
Iter n-m:  [████████████] → 存储到 Replay Buffer
Iter n-1:              [████████████] → 存储到 Buffer
Iter n:                          [████████] → 按需计算
```

避免从头重新生成长轨迹，支持异步工作。

### 5.3 混合部署

```
Megatron (训练) ◄──Mooncake(RDMA)──► vLLM (推理)
         │                                │
         └──────── Checkpoint Engine ─────┘
         (Kubernetes Sidecar)

切换时间: 训练→推理 < 1分钟, 推理→训练 ~ 10秒
```

### 5.4 Long2Short 方法

| 方法 | 效果 |
|------|------|
| 模型合并 | 简单平均权重，无需训练 |
| 最短拒绝采样 | 选最短正确回答做 SFT |
| DPO | 最短正确为正，较长为负 |
| **Long2Short RL** | **最佳 token 效率** |

### 5.5 防止奖励劫持

- 排除选择题、判断题、证明题
- **无 CoT 猜测测试**：8 次内猜对则排除
- 确保推理过程和答案都可验证
